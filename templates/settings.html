Privacy, Security & Data Retention

  • Zero Secret Leakage: API keys, server tokens, and credentials are never stored in the database, passed to client JavaScript, or exposed in HTML.
  • Local-First Storage: Analysis metadata is stored strictly in your local storage/truthlens.db file. No telemetry is collected.
  • User Deletion Control: You can delete any report at any time from the History page or via the Delete button on the report view.
  • SSRF & Network Protections: Private IP ranges (127.0.0.1, 10.0.0.0/8, 192.168.0.0/16, etc.) and metadata addresses are strictly blocked from URL analysis.
